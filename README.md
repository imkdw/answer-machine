# answer-machine

누가 질문하면 답 대신 URL을 보낸다. URL을 열면 몇 초간 병맛 연출이 나오고, 마지막에 뿅 하고 답변이 뜬다.

- 서버 없음. 답변은 URL 자체에 인코딩된다.
- 계획서: `docs/PLAN.md`

```bash
pnpm install
pnpm dev        # 개발 서버 (http://localhost:3939)
pnpm test           # codec 왕복 테스트 등
pnpm build      # 정적 빌드 (dist/)
```
